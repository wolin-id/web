02 · THE SOVEREIGN MANIFESTO

플랫폼 봉건주의와 투기적 크립토를 넘어,
디지털 실존을 위한 영속 백본으로.

수많은 웹·3D 플랫폼이 등장하고 사라지는 시대, 어떤 공간에 접속하더라도 개인과 기업이 신원과 데이터의 주권을 잃지 않도록 설계된 제3의 인프라 아키텍처입니다.

EPOCH I // WEB 2.0 PLATFORM LOCK-IN

사일로 감옥과 신원 종속

거대 플랫폼이 아바타, 친구 관계, 창작 에셋을 서버 내부에 가두어 락인합니다. 서비스마다 계정을 새로 만들고, 플랫폼이 종료되면 쌓아온 디지털 공간과 관계망이 함께 소멸합니다.

계정 정지 · 서비스 종료 = 디지털 자산 즉시 유실
EPOCH II // TOKEN WEB3 SPECULATIVE FRICTION

금융 투기화와 가스비 병목

데이터 주권을 표방했으나 토큰 이코노미와 온체인 가스비, 복잡한 시드 구문 UX에 매몰되어 실제 엔터프라이즈 SSO 및 일상적인 메타버스 경험으로부터 고립되었습니다.

단순 프로필 갱신조차 트랜잭션 비용과 지연 발생
EPOCH III // WOLIN (月印千江) SOVEREIGN POD CLOUD

월인천강(月印千江)의 시맨틱 주권

코인 발행 없이 표준 암호학 서명(WebID · DID · DPoP)만으로 신원을 증명합니다. 원본 데이터는 내 포드에 영속하며, 외부 월드에는 승인된 최소 범위만 실시간 투영합니다.

서비스가 사라져도 신원 · 아바타 · 데이터 영구 존속

crates/wolin-policy/src/pdp.rs · crates/wolin-server/src/ldp.rs
Solid 0.11 WAC / ACP 2.0 Zero-PII

외부 애플리케이션은 포드 전체 스토리지에 직접 접근할 수 없습니다. 모든 요청은 PolicyEngine::evaluate를 통과해 위임된 스코프(read, write, admin)를 검증받으며, 인가된 트리플만 직렬화되어 반환됩니다. 

// crates/wolin-policy/src/pdp.rs — Scoped Data Projection
impl PolicyEngine {
    pub fn project_request(
        principal: &Principal,
        uri: &ResourceUri,
        mode: AccessMode,
    ) -> Result<ProjectedGraph> {
        match PolicyEngine::evaluate(principal, uri, mode) {
            AccessDecision::Permit => project_subgraph(uri, principal),
            AccessDecision::Deny { reason } => deny(reason),
        }
    }
}
