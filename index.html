EPOCH I // WEB 2.0 PLATFORM FEUDALISM

사일로 감옥과 디지털 신원 종속

거대 플랫폼이 신원과 기억을 서버 내부에 가두어 락인(Lock-in)합니다. 서비스마다 계정을 새로 만들고, 개인의 사적 맥락과 기업의 핵심 자산까지 중앙 데이터센터에 종속되고 있습니다.

계정 정지 = 디지털 자아 및 관계망 즉시 소멸
EPOCH II // TOKEN WEB3 SPECULATIVE MIRAGE

금융 투기화와 가스비의 병목

데이터 주권을 표방했으나 토큰 이코노미와 비싼 온체인 가스비, 파편화된 시드 구문 UX에 매몰되어 실제 엔터프라이즈 IAM(SSO) 및 일상 소프트웨어로부터 철저히 고립되었습니다.

단순 프로필 변경조차 트랜잭션 비용 및 지연 발생
EPOCH III // WOLIN (月印) SOVEREIGN SEMANTIC WEB

월인천강(月印千江)의 시맨틱 주권

코인 발행 없이 암호학적 서명(WebID · DID · DPoP)만으로 무결성을 증명합니다. 원본 RDF 그래프는 내 포드에 영속하며, 외부 앱과 플랫폼에는 목적에 한정된 일회성 가상 뷰만 투영합니다.

외부 애플리케이션은 포드 전체 스토리지에 직접 접근할 수 없습니다. 모든 요청은 PolicyEngine::evaluate를 통과해 위임된 스코프(read, write, admin)를 검증받으며, 인가된 트리플만 직렬화되어 반환됩니다. 

// crates/wolin-policy/src/pdp.rs — Scoped Data Projection
impl PolicyEngine {
    pub fn project_request(
        principal: &Principal,
        uri: &ResourceUri,
        mode: AccessMode,
    ) -> Result<ProjectedGraph> {
        match PolicyEngine::evaluate(principal, uri, mode) {
            AccessDecision::Permit => project_subgraph(uri, principal),
            AccessDecision::Deny { reason } => deny(reason),
        }
    }
}
